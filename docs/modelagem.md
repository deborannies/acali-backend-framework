# Modelagem do Banco de Dados (DER)

Abaixo está o diagrama entidade-relacionamento (DER) focado exclusivamente no **Produto Mínimo Viável (MVP)** definido para esta disciplina. 

Para garantir a entrega funcional até o final do semestre (01/12), a modelagem foi restringida às entidades centrais: gestão de usuários, projetos, vínculo de equipe (tabela pivô), atividades e submissão de arquivos.
