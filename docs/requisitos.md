# Priorização de Requisitos: Matriz GUT

A técnica GUT foi utilizada para demonstrar a prioridade de implementação. O grau de prioridade de cada requisito é obtido pela multiplicação dos três fatores (G × U × T). Diante do prazo da disciplina, os requisitos com maior pontuação compõem o Produto Mínimo Viável (MVP) a ser entregue, enquanto os demais compõem o backlog futuro do projeto.
